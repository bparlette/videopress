# videopress

Manufacture viral short-form video from the command line.

```bash
videopress make episode.json   # clips + VO + captions -> episode.mp4
videopress thumbnail "TEXT"    # high-CTR thumbnail.png
videopress upload episode.mp4  # YouTube via Data API
videopress trust               # channel trust-signal check
```

Read **ORCHESTRATOR.md** — it's the one file an AI needs.
